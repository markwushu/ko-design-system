Components

Button

One primary button per section. Secondary and ghost exist for supporting actions only — never in competition with the primary.

Start the reset Learn more View all →
VariantFillBorderText
Primary--color-action-primary--color-action-primary--color-brand-ground
Secondarytransparent--color-border-default--color-text-default
Ghosttransparenttransparent--color-text-brand

Do

  • One primary button per visible section
  • Write labels as verbs: "Start the reset"
  • Full-width on mobile CTA sections
  • Match size to context — lg for hero CTAs

Don't

  • Use fake-urgent labels: "BUY NOW"
  • Place more than one primary per section
  • Truncate labels — resize the button
  • Uppercase labels (reads as shouting)
Components

Card

A contained visual unit. Cards contain content — they don't decorate it. Border radius maximum 2px.

Default card

Used on Ground (#FAF8F5) pages. 1px Ink border, 2px radius.

Tinted card

No border. Use on white or Ground backgrounds to add warmth.

Inverse card

Dark background for emphasis or feature highlights.

Do

  • Keep cards consistent in size within a grid
  • Let illustrations carry visual interest
  • Use tinted variant to group without hard borders

Don't

  • Add shadows to static (non-interactive) cards
  • Round corners beyond 2px
  • Put cards inside cards
Components

Form Elements

Precise and honest. No decorative chrome. Inputs are fully sharp — border-radius: 0. Labels are uppercase, small, above every input.

Do

  • Labels always above inputs
  • Placeholder shows an example value
  • Validate inline after field blur
  • Error messages appear below the field

Don't

  • Use placeholder text as the label
  • Round input corners at all — 0px is correct
  • Show all errors only on submit
  • Use floating labels

Do

  • One CTA only — never split attention
  • Aim for the "finally" register in the headline
  • Max 10 words in the headline

Don't

  • Use video backgrounds
  • Animate headline text
  • Add more than one button
  • Use stock photography or AI imagery
Components

Testimonial

Social proof that addresses specific objections. Place next to the claim it supports — not grouped at the page bottom.

"I've tried every productivity system going. This is the first one I've actually stuck to past week two."

— Sarah T., project manager

Do

  • Use specific, real testimonials
  • Include first name and context
  • Choose quotes that address real objections
  • Place adjacent to the claim they support

Don't

  • Use star ratings — they're generic
  • Use stock photo avatars
  • Group all at the page bottom
  • Use vague praise: "It's great!"

Brand

Principles

Eight principles that govern every design decision. When in doubt, return here.

01

Restraint earns trust

Every element asks: does this need to be here? If the answer is not clearly yes, remove it.

02

Honest over clever

Copy that tells the truth outperforms copy that sounds interesting. When in doubt, choose honest.

03

The tool serves the person

If a design decision makes the product harder to use, it is the wrong decision regardless of how good it looks.

04

Craft is visible at close range

Typography spacing, border weight, illustration line quality — details are not vanity. They signal care.

05

Specificity over abstraction

Generic language and generic design are interchangeable. Specific language and specific design are ownable.

06

Done examples over blank templates

A completed example is more useful than an empty framework waiting to be filled.

07

Anti-hustle, pro-calm

No manufactured urgency. No pressure tactics. A well-organised life creates space for what actually matters.

08

One clear next step

Every page, every section, every component has one primary action. Two competing CTAs cancel each other.
