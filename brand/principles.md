# Design Principles

These eight principles govern every design decision across Kept Organised — from token choices to layout decisions to copy calls. When in doubt, return here.

---

## 1. Restraint earns trust
The productivity market is full of visual noise competing for attention. Kept Organised earns attention through quality, not volume. Every element on every surface asks: does this need to be here? If the answer is not clearly yes, remove it.

## 2. Honest over clever
Copy that tells the truth outperforms copy that sounds interesting. Design that shows the work outperforms design that looks impressive. When there is a choice between honest and clever, choose honest.

## 3. The tool serves the person
The system exists to help the user, not to showcase the design. If a design decision makes the product harder to use, it is the wrong decision regardless of how good it looks.

## 4. Craft is visible at close range
The Hard Graft reference: products that reward close inspection. Typography spacing, border weight, illustration line quality — these details are not vanity. They signal that the same care applied to the product was applied to its presentation. Craft is the trust signal.

## 5. Specificity over abstraction
Generic language and generic design are interchangeable. Specific language and specific design are ownable. Be precise about what this product does, for whom, and what it changes.

## 6. Done examples over blank templates
A completed example is more useful than an empty framework. Pre-populated demos, worked examples, and done-for-you starting points always outperform blank canvases. The same applies to design: show the system working, not the system waiting.

## 7. Anti-hustle, pro-calm
No manufactured urgency. No pressure tactics. No celebration of busyness. The brand represents a different value system: a well-organised life creates space for what actually matters, and achieving that does not require suffering or sacrifice.

## 8. One clear next step
Every page, every section, every component has one primary action. Multiple competing calls-to-action cancel each other out. When you can't decide between two actions, that is a sign one of them shouldn't be there.

---

## Applied to implementation

These principles translate directly into technical decisions:

| Principle | Implementation |
|-----------|---------------|
| Restraint earns trust | Minimal border-radius, restrained shadow use, no decorative chrome |
| Honest over clever | No countdown timers, no fake scarcity, no value inflation |
| Tool serves person | Accessible focus states, clear error messages, readable line lengths |
| Craft at close range | Semantic token naming, clean CSS, 8pt spacing discipline |
| Specificity | Outcome-focused copy in button labels, includes lists, headlines |
| Done examples | Pre-filled demo content in product, worked examples in marketing |
| Anti-hustle | No urgency language in copy, no pressure patterns in UX |
| One clear next step | One primary button per section, clear visual hierarchy |
